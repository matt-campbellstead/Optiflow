# Optimum Freight Solutions

## A client-facing and internal business web application

A full-stack Node.js-Express app that allows customers to track their shipments and employees of OFS to handle business operations on a shared, easily-accessible platform.

# Features of this application

## Stack:

    - Node.JS
    - Express
    - MongoDB with Mongoose ORM
    - MariaDB with Sequelize ORM
    - Frontend is server-side rendered with PUG rendering engine
